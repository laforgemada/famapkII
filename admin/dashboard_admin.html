🎬 Vidéo Bonus

Collez un lien YouTube. Une fois validé, la vidéo s'affiche dans l'espace personnel de tous les utilisateurs. Chaque utilisateur reçoit +3 points de fidélité après avoir regardé la vidéo pendant environ 1 minute.

📱 Mise à jour de l'application (APK)

Collez le lien de téléchargement du fichier APK (ou de la page de téléchargement). Une fois validé, une notification « Nouvelle version disponible » est envoyée à tous les utilisateurs dans leur espace personnel. En cliquant dessus, ils pourront télécharger l'application ou scanner un QR code pour la partager.
